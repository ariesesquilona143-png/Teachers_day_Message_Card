# Teachers’ Day Message Card for Sir Randy Bello

A personalized, responsive Teachers’ Day greeting card built with HTML, CSS, and JavaScript. The design uses a warm cream-and-green palette, elegant typography, decorative details, and an interactive button that reveals an extra appreciation message.

## Features
- Personalized greeting for Sir Randy Bello
- Responsive layout for desktop and mobile screens
- Custom colors, typography, and decorative styling
- Interactive appreciation button
- Accessible button labels and keyboard focus styling
- Reduced-motion support

## Project files
- `index.html` — page content and card structure
- `style.css` — colors, layout, typography, and responsive design
- `script.js` — reveal/hide interaction

## How to use
1. Open the repository on GitHub.
2. Open `index.html` in a browser, or publish the repository with GitHub Pages.
3. To personalize the message further, edit the greeting and message paragraphs in `index.html`.
4. Change colors and fonts in `style.css` if desired.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder.
4. Save and wait for GitHub Pages to publish the site.
